# User Guide

Run `python main.py`. Type the number of the option you want and press Enter.
Each sub menu has a Back option at the end. Option 7 in the main menu exits.

1. Datetime and Time - current date/time, days between two dates (YYYY-MM-DD),
   custom date format (like %d/%m/%Y), stopwatch (Enter to start, Enter to stop),
   countdown (enter seconds), working hours (enter times like 09:00 and 17:30).
2. Mathematical Operations - factorial, compound interest, sin/cos/tan (angle in
   degrees), area of shapes, logarithm (base 0 = natural log), unit conversions,
   GCD/LCM and prime check.
3. Random Data - random number, list, password, OTP, random sampling
   (items separated by commas) and a dice game against the computer.
4. Unique Identifiers - UUID, invoice ID and session ID.
5. File Operations - create a file first, then write, read, append, or replace text.
   Files are created in the same folder as main.py.
6. Explore Module Attributes - type a module name such as `math` or `random`.
   For our own modules type `toolkit.math_utils`.

All actions are saved in toolkit_log.txt.
